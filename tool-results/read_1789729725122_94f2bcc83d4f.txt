   260→Work Log:
   261→- Analisis root cause: Sonner secara default PAUSE auto-dismiss timer saat window kehilangan fokus (blur). Saat window.open(url, "_blank") dipanggil untuk buka report di tab baru, parent window blur → timer pause → toast stuck forever.
   262→- Fix 1: Set `duration={4000}` eksplisit di SonnerToaster (default 4s untuk semua toast)
   263→- Fix 2: Tambah `closeButton` di SonnerToaster — user bisa manual dismiss via tombol X
   264→- Fix 3: Tambah `expand={false}` — keep toast compact
   265→- Fix 4 (KEY FIX): Di report-dialog, capture toast ID dan manual dismiss via setTimeout:
   266→  ```ts
   267→  const toastId = toast.success("...");
   268→  if (typeof toastId === "string" || typeof toastId === "number") {
   269→    window.setTimeout(() => {
   270→      try { toast.dismiss(toastId); } catch {}
   271→    }, 4000);
   272→  }
   273→  ```
   274→  setTimeout tidak di-pause oleh Sonner's blur logic, jadi toast pasti dismiss setelah 4s bahkan jika user sudah pindah ke tab report.
   275→- Cleanup: hapus radix Toaster yang tidak terpakai dari layout (hanya Sonner yang dipakai di semua SPJ components)
